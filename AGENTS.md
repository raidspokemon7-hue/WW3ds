# For anyone modding or forking WW3ds with AI

This file is for anyone who wants to mod or fork WW3ds with an AI agent. Give the agent this repository and tell it to follow this file. The README is the player page. This file is the one for code changes.

WW3ds is a native port of the USA GameCube Wind Waker, game ID GZLE01, to New 3DS, New 3DS XL, and New 2DS XL. It runs the game's own code. It is not an emulator. The original 3DS and 2DS are not supported. The game comes from the zeldaret/tww decompilation. No disc image, extracted Nintendo assets, or Nintendo music belong in the repo.

## Where the code is

- `source/new3ds` is the console entry, input, audio, first boot, packaging, and `ww_build.sh`.
- `source/graphics` is the GX-to-PICA renderer.
- `system/new3ds` is the host-tested copy of the shortcut, save-option, and lifecycle headers. Keep it in step with `source/new3ds/src` when those headers change.
- `utilities` holds the texture converter, SD export, release prep, console logs, timing overlay, and bottom-screen art.
- `sd-card-installer` is the PC installer.
- `host-tests` is `python3 host-tests/run.py`.
- `media` is the GitHub banner.

The console compile uses container paths `/arm/src` and `/hw6`. Those paths are not the folder names in this repo. `source/new3ds/ww_build.sh` is the build script. A full console build needs devkitARM and a SwitchWaker checkout at `~/ww-port/SwitchWaker`. `3dsxtool` is `/opt/devkitpro/tools/bin/3dsxtool`.

## Leave these alone unless the person asked

Player files live under `sdmc:/3ds/ww3ds` (same tree the SD zip unpacks).

- The disc is a USA GZLE01 image at `3ds/ww3ds/game/GZLE01.iso` or `3ds/ww3ds/game/GZLE01.ciso` (Dolphin/Wiimm sparse CISO). NKIT/RVZ/PSP CSO do not boot. `sdmc:/ww3ds/game/` is also scanned as a fallback.
- Saves are at `3ds/ww3ds/saves/USA/Card A`. A `.gci` or Dolphin `.raw` dropped in `saves/` is imported into Card A on the next boot, then moved to `saves/imported/`.
- The first launch shows "Preparing Wind Waker" with a one-way percent bar, blocks input, and writes `first-run.done`. Percent never goes down. It hits 100% only after enough warm work (active frames, good frame times, shader cache growth), then opens the title. After 90 seconds it forces 100% and opens anyway.
- `qol.ini` keys stay `sail`, `fast_grapple`, `no_song_replay`, `instant_text`, `gyro`, `gyro_sensitivity`, `gyro_invert_x`, and `gyro_invert_y`.
- `shortcuts.ini` uses `slot1.action`, `slot2.action`, and `slot3.action`.
- `performance.ini` keeps the snake_case keys in `source/new3ds/src/ww_performance_3ds.h`. The C++ fields are the names on `g_tuning`, such as `cacheMaterials` and `lowerScreen`. `foliage_far` defaults to 2500 (trees/grass only). `real_shadows` defaults to 0. `skip_draw` and `frame_skip` default to 0. `rigid_clip` defaults to 0.
- Do not edit strings marked `generated by tev2pica`.
- Do not commit ISOs, CIAs, ELFs, keys, saves, or private paths.
- The credit list stays zeldaret/tww.

After a code change, run `python3 host-tests/run.py`.

## Forking

Change the README and the HOME Menu title in `source/new3ds/ww_package_cia.sh` and `source/new3ds/package_full.sh`. Keep Nintendo's game out of the fork. Keep the licence notices that sit next to vendored code.
